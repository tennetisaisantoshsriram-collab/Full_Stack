What is the DOM?

The Document Object Model (DOM) is a programming interface provided by the browser. When a browser loads an HTML page, it parses the markup and builds a tree-like structure in memory — the DOM tree — where every HTML tag becomes a node (object). JavaScript can then read and manipulate these nodes to change what the user sees, without reloading the page.

  • Content — via innerHTML / textContent
  • Style — via element.style or classList
  • Attributes — via setAttribute() / getAttribute()
